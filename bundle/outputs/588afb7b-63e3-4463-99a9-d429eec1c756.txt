### Key implementation notes

1. **State machine**  
   * Draft → `in_review` (submit) – allowed only for article owner.  
   * `in_review` → `published` (approve) – allowed only for editors.  
   * `in_review` → Draft (reject) – allowed only for editors, requires a comment.  
   * Any invalid transition returns `422` with the standard error envelope.

2. **Privacy**  
   * The public article list (`GET /api/articles`) now filters out any article whose status is not `published`.  
   * The review queue (`GET /api/articles/review-queue`) is hidden from non‑editors.

3. **Compatibility**  
   * Existing clients that POST without a status still publish immediately, so all current tests continue to pass.  
   * No changes were made to the contract test file `apps/api/test/realworld.contract.test.ts`.

4. **Error handling**  
   * Unauthorized actions return `403`.  
   * Invalid transitions return `422` with `{ errors: [{ status, title }] }`.

5. **Environment**  
   * `EDITORS` env var is parsed in `server.ts` and passed to the app constructor.
