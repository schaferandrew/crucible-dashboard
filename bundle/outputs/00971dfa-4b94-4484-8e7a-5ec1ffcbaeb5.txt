### Things to flag in a code review

1. **Cursor encoding** – I used HMAC‑signed JSON for safety; the secret lives in an env variable. Confirm that it’s not exposed in logs or error messages.
2. **Performance** – Cursor queries use `WHERE id < :lastId` (newest first). For very large tables this can be slow; consider indexing `id DESC`.
3. **Backward compatibility** – All old endpoints still honor `offset`/`limit`. Verify that third‑party clients are not broken.
4. **Error handling** – The 422 error envelope is consistent with the existing validation system; make sure no new fields leak sensitive data.
