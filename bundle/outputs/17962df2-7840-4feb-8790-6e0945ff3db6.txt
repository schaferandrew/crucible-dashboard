Done. Here's a summary of the diagnosis and fix:

## Diagnosis
`app/page.tsx` used `React.useState`/`useEffect` with no `'use client'` directive — it was written as if it were a client component but rendered as a server component, so the production build failed (`Property 'name' does not exist on type 'never'` from `useState(null)` narrowing to `never`). Even past that, the pattern was wrong for App Router: fetching its own API route from the client just to render initial data is an anti-pattern — server components should read data directly. The page also carried a dead duplicate copy of the accounts data and showed "Loading..." forever in any failure case.

## Fix (idiomatic modern Next.js)
- **`lib/accounts.ts`** (new): shared `Account` type, simulated database, and `getAccount(id)` helper — single source of truth for both the page and the API route.
- **`app/page.tsx`**: now an async server component that reads acct_1 directly via `getAccount()` and renders name/plan (with a not-found fallback instead of a permanent "Loading..."). No client hooks, no self-fetch, no loading state needed.
- **`app/api/account/route.ts`**: kept as the external API surface, but now backed by the shared `getAccount()` (removed its duplicated data copy and unsafe cast).
- **`app/layout.tsx`**: imports `ReactNode` type properly instead of relying on a global `React` namespace.

## Tests
- Moved the API route tests to `app/api/account/route.test.ts` (import path fixed) — still cover 200 for acct_1 and 404 for unknown id.
- New `app/page.test.tsx`: renders the async server component and asserts "Name: Alice" / "Plan: Pro" appear — this covers the actual bug.

## Verification
- `npm test`: 3/3 passing (2 route + 1 page).
- `npx next build`: succeeds; `/` prerenders statically, `/api/account` is dynamic.
- Production server smoke test: HTML contains Alice/Pro and `GET /api/account?id=acct_1` returns `{"name":"Alice","plan":"Pro"}`.

Note: `next-env.d.ts` was regenerated by the build (added Next's standard comment block) — that's a normal artifact, left as-is.
