# Golden diff: what the new core does differently from the old page

_Generated by `WRITE_GOLDEN_DIFF=1 npm test` from `tests/parity.test.ts`; do not edit by hand. Each allowed difference matches exactly one rule in `tests/allowlist.ts`; a difference with no rule fails the test._

The test reproduces 84 leaderboard scenarios of `golden-numbers.json` (suites v4 and v3, sections chat, agentic and Combined, provisional off and on, each tier left out in turn, in-progress rows hidden and shown) plus sort orders, single-filter boards (harness, where, hw, reasoning) and facet counts. That is 3164 golden rows; 1760 match on every compared field, 572 differ only in rank (shifted by the rows above them) and 832 carry another allowed difference. Rows are matched by model and reasoning level, ignoring case.

Not compared, because the value grammar changed rather than the numbers: filters on `format`, `quant` and `packager` (the page guessed `splash`, `mlx-4bit` and publisher spellings; the registry now records `mlx`, `4bit`, the packager). Time, tok/s and cost are compared on non-excluded scenarios only, because the old page ignored the tier toggles for them.

Also expected, with no numeric difference: **B-14** (the Granite maker is `ibm-granite` everywhere, was `ibm` in some paths) changes a label, not a row key or a score; **B-07** (rank is always rank by Overall) is the rank definition used here, and since the golden boards are sorted by Overall it only shows as the rank shifts below.
